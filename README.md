# 📊 Sales Performance Dashboard – Excel

## 📌 Project Overview

The **Sales Performance Dashboard** is an interactive Excel dashboard created to analyze and visualize sales data. The project transforms raw sales records into meaningful business insights using **Excel formulas, Pivot Tables, Pivot Charts, slicers, and data visualization techniques**.

The dashboard provides a clear overview of **sales, profit, quantity, customer segments, product categories, and regional performance**, helping users understand business trends and identify areas for improvement.

## 🎯 Project Objectives

- Analyze overall sales and profit performance.
- Track key sales performance indicators (KPIs).
- Identify top-performing categories and sub-categories.
- Compare sales performance across different regions.
- Analyze monthly and yearly sales trends.
- Understand customer segment performance.
- Identify high-performing and low-performing areas.
- Support data-driven business decision-making.

## 📈 Dashboard Features

- **Total Sales**
- **Total Profit**
- **Total Quantity Sold**
- **Average Sales**

- **Yearly Sales Analysis**
- **Regional Sales Analysis**
- **Category & Sub-Category Analysis**

- **Interactive Filters and Slicers**
- **KPI Cards and Charts**

## 💡 Key Insights

The dashboard helps identify:

- Which regions generate the highest sales and profit.
- Which categories and sub-categories perform best.
- How sales change over time.
- Which customer segments contribute the most to sales.
- Areas with lower sales or profitability.
